# WORK 페이지 구현 기준

- 상위 디자인 계약: 바탕화면 SORO_원본_디자인_개발키트/design-system/DESIGN.md.
- 구성 근거: 2026-09-27 사용자가 제공한 구성 이미지. 디자인 근거로 사용하지 않는다.
- 제목 제안: Featured Work.
- 서브텍스트 제안: 업종의 특성과 일하는 방식을 담아, 각 기업에 맞는 공간을 만듭니다.
- 필터: 전체, 바이오, 반도체, IT, 건설, 제조, 미디어, 금융, 서비스. 전체 포함 9개.
- 프로젝트 데이터: 사용자 이미지에서 읽은 3건 + 사용자가 요청한 샘플 3건. 샘플 표시와 isDummy 플래그를 유지한다. PC는 한 줄 4개(6개 콘텐츠는 4+2), 태블릿은 3열, 모바일은 2열×3줄.
- 사진, 프로젝트명, 업종, 평수 상시 노출.
- 기본 UI: .sub-container > .sub-wrap > .sub-title + .work-filter + .work-list 원본 계층.
- 원본 보존: CSS 3개 원문, Pretendard Variable, 제목·서브텍스트·메타 타이포, 필터 베이지/검정, 정사각형 이미지와 얇은 선, 원본 gap.
- 구성 확장: 최신 사용자 요청에 따라 데스크톱은 4열. 1200px 이하는 3열, 768px 이하는 원본 2열.
- 기능 확장: 데이터 필터, 실제 건수, aria-pressed/라이브 결과 안내, 빈 상태·전체 복귀, 키보드 focus, reduced-motion.
- 9개 버튼을 작은 화면에 담기 위해 flex-wrap을 추가. 사용자 요청에 따라 필터 컨테이너 배경은 투명하게 유지한다.
- 상단 메뉴: 사용자가 제공한 로고를 사용하고, 디자인코드 / 프로젝트 / 프로세스 / 상담신청 순서로 배치한다. 상담신청은 검정 버튼이다. 데스크톱 30px 좌우 여백, 17px 메뉴 글자, 40px 간격은 원본 헤더 규칙을 따른다. 모바일은 원본처럼 검정 전체 화면 메뉴와 토글을 사용한다.
- 메인 제작 이후 디자인코드는 index.html#about, 프로세스는 process.html, 상담신청은 index.html#contact로 연결한다. 프로젝트는 work.html에 유지한다.
- 상세 페이지 정보가 없으므로 카드에 빈 링크를 만들지 않는다. 상세 페이지 제작은 후속 범위.
- 관찰용 가이드 CSS 및 이전 확장 토큰을 로드하지 않는다.
- 새로운 제목·고객 콘텐츠를 사용하므로 원본 페이지 전체 픽셀 일치를 주장하지 않는다.

## 고객 타이포 언어 규칙 (2026-09-27 사용자 지정)
페이지 제목 타이틀은 영문, 서브텍스트는 한글로 작성한다. 프로젝트명과 업종 등 데이터는 실제 이름을 유지한다. 원본 CSS의 타이포 수치는 변경하지 않는다.
