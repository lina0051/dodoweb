C O + D E 협업으로 완성하는 공간 디자인

디자인코드는 Cooperative Design의 철학에서 출발했습니다. 협력을 뜻하는 ‘co’와 디자인을 뜻하는 ‘de’를 결합한 이름입니다.

고객의 생각과 현장의 조건, 설계자의 경험을 하나의 기준으로 연결합니다. 처음 나눈 이야기부터 설계와 시공, 공간을 사용하는 순간까지 같은 방향을 바라보며 완성도를 높입니다.
